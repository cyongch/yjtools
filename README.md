# 即用工具箱

**36 个免费在线工具，全部在浏览器本地运行——文件不上传、不联网也能用。**

纯静态站点，零构建、零后端。打开网页即用，所有处理（PDF 改写、图片编解码、哈希计算、加解密）都由浏览器原生能力完成，文件从头到尾不离开你的电脑。

## 为什么选择本地处理

大多数在线转换工具会把文件上传到服务器加工再传回来。你的合同、报价单、图纸截图在别人服务器上停留多久、有没有被留存，你无从得知。

本站所有工具都使用浏览器的原生能力（Canvas、WebAssembly、Web Crypto）在本机完成计算。**你可以直接断开网络，页面照常工作。**

## 使用方式

- **在线访问**：<https://cyongch.github.io/yjtools/> —— 无需安装、无需注册。
- **本地打开**：克隆仓库后双击 `index.html`。整站不用 ES Module、不发起网络请求，`file://` 协议下可完整运行。

## 技术上做不到的事

纯静态架构没有服务端，因此以下能力**明确不做**，以免给出错误的结果：

- Word / Excel / PPT 与 PDF 之间的**高保真互转**（依赖服务端排版引擎）
- 扫描件 OCR 文字识别（需 15 MB 级模型且中文精度有限）
- 音视频转码（需 25 MB 级 WASM 引擎）

## 目录结构

```
├── index.html              首页（搜索 + 分类筛选）
├── assets/
│   ├── style.css           全站样式（浅色为主，自动适配暗色）
│   ├── tools-data.js       工具清单数据（新增工具在此登记）
│   └── app.js              公共函数与首页逻辑
├── tools/<工具名>/index.html   每个工具一个独立页面
├── vendor/                 第三方库（已本地化，不依赖外部 CDN）
└── PLAN.md                 项目说明：架构、约束、部署、扩展指南
```

## 自检

项目自带两个零依赖的自检脚本（需要 Node.js）：

```bash
node _check.js   # 语法自检：逐个编译页面内的脚本块
node _test.js    # 逻辑自检：渲染、筛选、算法断言
```

`_test.js` 会**从 HTML 里提取真实的内联脚本**并在 Node 中执行，因此测的是页面上真正运行的代码，而非复制品。

## 新增一个工具

1. 新建 `tools/<工具名>/index.html`，照抄任一现有工具的骨架；
2. 在 `assets/tools-data.js` 中登记（`href` 要写完整路径 `tools/<工具名>/index.html`）；
3. 跑一次 `_check.js` 与 `_test.js`。

详见 [PLAN.md](PLAN.md)。
