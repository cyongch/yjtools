CSV / JSON / Markdown 表格互转

三种表格数据格式任意互转，正确处理引号、逗号与换行等转义情况。

数据不上传转换在页面内完成，可放心粘贴清单、报表数据。

输入内容后点「转换」，或直接切换输出格式即时重算。

三种格式各自的用途

  • CSV：Excel、WPS、数据库导入导出的通用格式。优点是简单；缺点是所有值都是文本，不区分数字与字符串，且没有嵌套结构。
  • JSON：程序之间交换数据的标准格式，能表达嵌套对象与数组。把 CSV 转成 JSON 是导入接口、写脚本时的常见需求。
  • Markdown 表格：写文档、写公众号、提交 Issue 时展示表格用。转过去后可直接粘贴进 Markdown 编辑器。

转义规则

CSV 的坑几乎都在转义上。本工具按 RFC 4180 处理：

  • 字段内含分隔符、双引号或换行时，整个字段用双引号包裹。
  • 字段内的双引号写成两个连续双引号（""）表示一个引号。
  • 反过来解析时，被引号包裹的字段内部的换行与逗号不会被当作分隔，所以「工程内容里带逗号」这类数据不会串列。

JSON 转表格的前提

输入 JSON 需要是「对象数组」，形如 [{"a":1},{"a":2}]，键名会作为表头。如果传入的是单个对象，会被当作只有一行处理。嵌套的对象或数组会被转成 JSON 字符串放进单元格——因为二维表格本身无法表达层级结构。

数据安全

全部转换在浏览器内完成，不发送任何数据。处理内部清单、报价明细时可直接使用。
