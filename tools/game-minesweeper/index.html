扫雷

经典扫雷，三种难度。第一下永远不会踩到雷，放心点。

纯本地运行布雷与判定全部在本机完成，不联网、不上传。

玩法

桌面下埋着若干颗雷，翻开格子会显示它周围八格中雷的数量。用这些数字推理出雷的位置，把所有非雷格子翻开即获胜。踩到雷则本局结束。

  • 左键单击：翻开格子。翻到空白（周围 0 颗雷）时会自动向外扩散。
  • 右键单击：插旗标记你认为是雷的位置。旗子占位但不会翻开。
  • 双击已翻开的数字：如果它周围插的旗数已经等于这个数字，会自动翻开其余格子。这是扫雷里最快的操作方式。
  • 手机 / 平板：没有右键，点上面的「旗帜模式」按钮切换，再点格子就是插旗。

本工具的贴心处理

  • 首点永不踩雷：第一次点击的位置及其周围八格保证没有雷，避免开局就结束。
  • 点错也不致死：双击快速展开时，如果旗子插错导致周围还有未标记的雷，不会立即引爆，而是先提示你。这让手快的人不至于误触。
  • 不需要猜：采用"从零扩散"的布雷方式，绝大多数局面可以纯靠推理走完。

常用推理套路

  • 1-1 型：两个相邻的 1 挨着同一侧空白时，外侧那格一定是雷。
  • 1-2-1 型：一条边上的 1、2、1，两端的 1 对应的外侧格是雷。
  • 数字等于周围空格数：说明周围全是雷，直接全部插旗。
  • 先把所有"确定的"标记完，再从确定的格子向外推理，比东一榔头西一棒子快得多。
