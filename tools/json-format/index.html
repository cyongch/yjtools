JSON 格式化 / 校验

格式化、压缩、校验 JSON 数据，出错时直接告诉你第几行第几列有问题。

支持自动识别常见的非标准写法（单引号、尾随逗号）。

这个工具能做什么

JSON 是接口返回数据、配置文件、系统导出数据最常见的格式，但机器生成的 JSON 通常挤在一行里，人根本没法读。这个工具把它还原成带缩进的层级结构，或者反过来把格式化好的 JSON 压成一行，方便传输。

校验失败的场景更常见：少了一个逗号、多了一个括号、字符串用了单引号。多数工具只会说一句"解析失败"，这里会给出具体行号、列号，以及该位置附近的原文片段，定位通常只需要几秒。

使用说明

  • 把 JSON 粘贴到左侧输入框，点击「格式化」即可。
  • 「压缩成一行」用于减小体积；「转义为字符串」把整段 JSON 变成一行可嵌入代码的字符串。
  • 「去转义」用于把从日志或代码里复制出来的转义字符串还原成可读 JSON。
  • 大纲数据量大时（数万行）浏览器仍能处理，但首次解析会有短暂停顿。

关于数据安全

解析全部由浏览器自带的 JSON.parse 完成，整个页面没有任何网络请求。如果你的 JSON 里包含报价、合同条款等敏感信息，可以放心使用。
