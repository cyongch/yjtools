哈希有什么用

哈希（散列）是把任意长度的数据压成一段固定长度"指纹"的算法。相同内容一定得到相同指纹，内容改一个字符指纹就完全不同，而且无法从指纹反推出内容。常见的用途有三个：

  • 校验文件完整性：下载完安装包或图纸包后，和发布方给的 MD5 / SHA-256 比一下，一致说明传输中没有损坏或被篡改。
  • 确认两份文件是否相同：文件名不同但内容一样，哈希值会完全相同，比逐字节对比更快。
  • 留痕存档：对已定稿的报价文件、结算书取一次摘要并记录，日后可证明文件未被改动。

如何选择算法

  • MD5：最快，兼容性最好，很多网站用它发布校验值。但抗碰撞性已被攻破，不要用于安全场景，仅适合做完整性校验。
  • SHA-1：同样已被认为不安全，多用于兼容老系统。
  • SHA-256：当前推荐的标准选择，安全且性能足够，优先用它。
  • SHA-384 / SHA-512：强度更高，摘要更长，用于对安全性要求更严的场合。

数据安全

MD5 由页面内嵌的算法库计算，SHA 系列调用浏览器原生 Web Crypto 接口。整个过程不产生网络请求，图纸、合同等文件可以放心拖进来。
