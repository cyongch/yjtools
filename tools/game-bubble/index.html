用法

在泡泡纸上按住鼠标拖动，经过的泡泡会依次被捏破；手机上用手指滑过去也一样。想一个一个捏也行，单击即可。点「一键全捏」可以听一遍完整的连响，纯爽感用。

关于声音

页面里的"啵"声不是加载的音频文件，而是用浏览器的 Web Audio 接口实时合成的——一个频率快速下滑的短音，模拟气泡破裂的听感。这样既不占用流量，也让每个泡泡的声音都略有不同，听起来更自然。

浏览器出于防止广告自动播放的考虑，要求音频必须由用户操作触发。所以如果你没听到声音，先在页面上点一下即可。也可以直接把声音切到"关闭"，安静地捏。

为什么捏泡泡会让人放松

泡泡纸之所以成为经典的解压道具，原因有几层：即时的反馈（按下去立刻有变化和声响）、零决策成本（不需要思考下一步做什么）、有明确的边界（捏完就结束了，不会像信息流一样无限延续）。

在线版本保留了前两点，并且额外解决了实体泡泡纸的两个问题：不会用一张少一张，也不用攒着不敢捏。
