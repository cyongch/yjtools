PDF 元数据修改

查看并修改 PDF 内嵌的标题、作者、主题等信息，外发前抹掉你的名字与内部标题。

文件不上传元数据的读取与写入都在本机完成，涉密文件可放心使用。
把 PDF 拖到这里，或点击选择 选完会自动读出现有元数据

    为什么要在外发前清理元数据

    PDF 文件内部除了正文，还会记录一批「文档属性」。这些信息平时看不见，但任何人用阅读器查看属性就能读到：

    • 作者：常是你的系统登录名（如 administrator 或真实姓名）。
    • 标题：往往是内部完整文件名，可能含项目代号、客户名、版本号。
    • 创建/生成程序：暴露你用的软件与版本，例如从某造价软件导出的痕迹。

    投标文件、发给甲方的报价、对外公布的图纸册，都建议先清一遍。这类信息不构成技术泄密，但足以暴露内部流程与人员，属于「不必要的信息暴露」。

    操作说明

    拖入 PDF 后，表单会自动填好现有元数据。直接改内容，点「生成新 PDF」即可。原文件不会被修改，输出是一份新文件。若只想抹掉个人信息，点「一键清空全部元数据」再生成。

    元数据支持中文，写入采用 PDF 标准的 Unicode 编码，不会出现乱码。

    说明

    本工具处理的是文档属性（Info 字典），不涉及 PDF 内嵌的 XMP 元数据包、书签、附件与注释。如果你的场景要求彻底清理（例如对外公开发布），除本文具外，还建议检查是否有内嵌附件与批注。
