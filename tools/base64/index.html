Base64 编解码

文本与 Base64 互转，中文、emoji 都不会乱码，支持 URL 安全字符集。

数据不上传编码解码在页面内完成，不产生任何网络请求。

提示：Ctrl / Cmd + Enter 可快速执行编码。

什么是 Base64

Base64 是一种把任意字节数据转换成 64 个可打印字符的编码方式。它不是加密，只是"换个写法"——任何人拿到 Base64 都能还原出原文。它的用途是让二进制数据能够安全地塞进只允许文本的场合，比如邮件正文、URL 参数、JSON 字段、CSS 内嵌图片。

常见误区

  • 中文乱码：不少简易工具直接用 btoa，遇到中文就报错或乱码。本工具先按 UTF-8 转字节再编码，中文、日文、emoji 都正常。
  • URL 里被截断：标准 Base64 含 +、/、=，放进 URL 或文件名会被转义甚至截断。勾选「URL 安全字符集」可解决。
  • 体积会变大：Base64 编码后体积约为原始的 133%，不适合用来压缩数据。

使用说明

左侧输入明文点「明文 → Base64」；右侧粘贴 Base64 点「Base64 → 明文」反解。解码时会自动忽略换行与空格，所以从配置文件里跨行复制的 Base64 也能直接粘贴。
