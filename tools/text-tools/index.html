常见用途

  • 清单数据清洗：从系统导出的材料表、清单表常带大量空行和重复行，一键清理后再粘贴进 Excel。
  • 材料名称规范：把混乱的大小写、全角括号、多余空格统一成规范写法。
  • 提取关键信息：从大段文字里批量提取金额数字、网址、邮箱。
  • 去重核对：核对供应商名单、编码列表是否存在重复项。
  • 字数统计：写方案、写公众号文章时快速查看字数构成。

处理逻辑说明

以「行」为基本单位处理，不会跨行合并内容（除非你主动使用「换行转空格」）。「删除重复行」保留首次出现的顺序；「升序 Z→A」按字符编码排序，中文按拼音顺序不受支持（浏览器原生排序规则所限）；「按数字大小」会提取每行中首个数字作为排序依据，适合给编码、序号排序。

「全角转半角」会把中文标点之外的ＡＢＣ、１２３、（）等全角字符转成半角，处理从 PDF 或网页复制来的文本时特别有用。

数据安全

全部处理由页面内的 JavaScript 完成，不发送任何数据。可断网使用。
