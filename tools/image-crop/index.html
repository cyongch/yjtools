图片裁剪

在图片上直接拖出要保留的区域，或用比例锁定精确裁剪。

图片不上传裁剪在本机完成，不会产生任何上传请求。
把图片拖到这里，或点击选择 支持 JPG、PNG、WebP、BMP

    在图片上按住鼠标拖动即可框选；也可以直接填上面的数字精确指定（单位为原始像素）。

    选择图片后在此框选要保留的区域

    比例锁定的用处

    • 1:1：头像、证件照、方图排版。拖动时会自动保持正方形，省得反复调整。
    • 4:3 / 16:9：PPT 插图、视频封面、公众号封面（常见 2.35:1 或 16:9）。
    • A4 竖（1:1.414）：裁剪后正好铺满一张 A4，打印不浪费纸。

    操作方式

    拖入图片后，在预览图上按住鼠标左键拖动即可框选。松开后可以微调：直接修改下方的 X / Y / 宽 / 高数值，或在图上重新拖一个新框。选框外的区域会变暗，便于确认保留范围。

    裁剪按原始像素执行——预览图是缩小显示的，但导出的是你框选区域对应的原始分辨率，因此不会有清晰度损失。

    常见用途

    • 把手机截图里的多余部分裁掉，只保留正文区域。
    • 从图纸截图中裁出需要的节点大样。
    • 裁掉扫描件的黑边与装订线阴影。
    • 把横幅照片裁成正方形用于头像。

    数据安全

    裁剪在浏览器内完成，图片不上传，可断网使用。
